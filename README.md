# 狐の育成ゲーム (fox)

スマホのブラウザで完結して遊べる、狐のお世話育成ミニゲームです。セーブ機能はなく、1回のプレイでたまごから育て上げるまでを楽しむ形になっています。

## 遊び方

1. `index.html` をブラウザで開くと、まず「たまご」の状態からスタートします
2. 画面下部の「あたためる」ボタン（キー: `Space` / `W`）を連打してたまごをあたためます。あたため度が満タンになると孵化して、こぎつねが生まれます
3. 孵化すると画面下部が4つのボタン（またはキーボード）に切り替わり、そこから狐のお世話をします
   - **エサ**（キー: `1` / `F`）: 満腹度が増える
   - **あそぶ**（キー: `2` / `P`）: 機嫌が良くなるが、体力と満腹度を少し消費する
   - **そうじ**（キー: `3` / `C`）: 清潔度が増える
   - **ねる**（キー: `4` / `S`）: トグル式。寝ている間は体力が回復し、満腹度・機嫌・清潔度の減りも緩やかになるが、エサ・あそぶ・そうじの操作はできない。体力が満タンになると自然に起きる
4. ボタン以外の場所で狐を直接タップすると「なでる」ことができ、機嫌が少し良くなってハートが出ます（寝ている間や病気のときもなでられます）
5. 画面上部には4本のステータスバー（まんぷく・きげん・せいけつ・たいりょく）が表示されます。いずれもお世話をしないと時間経過で減っていき、どれか1つでも赤いしきい値を下回ると他のステータスの減りも早くなります
6. お世話不足の状態が続くと、確率で**病気**になってしまいます。病気の間は遊べず、機嫌と体力の減りが早くなり、成長も止まります。画面に現れる「くすり」ボタン（キー: `5` / `M`）で治してあげましょう
7. **朝と夜**が交互に訪れます。夜は空が暗くなって月と星が出ます。夜に寝かせると体力の回復が早くなります
8. 「ねる」で寝かせると狐は丸くなって横になり、すやすや眠ります（Zzz）
9. お世話が行き届いている（4つの平均ステータスが一定以上を保てている）時間が積み上がると、狐が「こぎつね → わかぎつね → せいじゅうのきつね」の順に成長します。成長すると狐の見た目が一回り大きくなり、お祝いのバナーが表示されます
10. 機嫌が良いとしっぽを大きく振り、笑顔になります。逆にステータスが低いと悲しい表情になります
11. ゲームオーバーはありません。せいじゅうのきつねまで育てたあとも、そのまま自由にお世話を続けられます

## 構成

- `index.html` — キャンバスとビューポート設定
- `game.js` — ゲームロジック一式（設定・お世話・ステータス管理・成長判定・描画・ループ）

ビルド不要。`index.html` を開くだけで動作します。
